KGmemory · glass box

A memory you can open and check

An AI assistant forgets everything between conversations. KGmemory gives it a long-term memory stored as a graph of facts, where every fact keeps a link to the sentence it came from. Pick a question below and look inside.

KGmemory is an external memory for LLM agents: RDF memories in a triple store, SKOS concepts, SHACL-gated writes, and a PROV-O activity for every mutation. Pick a question below and open each stage of the pipeline.

2 Read

How those memories were found

No large language model is called to find memories. The question is matched to topics, the graph is followed from those topics, and the candidates are ranked and trimmed to fit a size limit. Open a step to see what it produced for this question.

Retrieval is deterministic and local: concept resolution by embedding, one SPARQL CONSTRUCT over the SKOS neighbourhood, a dense content channel fused by RRF, a cross-encoder window, then packing under a character budget. Timings are the ones recorded for this call.
